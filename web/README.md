# Игровая комната «Мику и друзья»

Статический сайт без сборщика и внешних зависимостей. Откройте `index.html` или запустите HTTP-сервер из этой папки.

## Игры

- `index.html` — бесконечная игра «Три в ряд».
- `merge.html` — пиксельная merge-игра «Слияние звёзд»: роняйте фишки, соединяйте одинаковых персонажей и открывайте следующую ступень. Шарики перекатываются друг по другу и крутятся при столкновениях.
- `go.html` — классическое го на стандартной доске 19 × 19 для двух игроков: Мику играет чёрными, Тето — белыми. Ставьте камни на пересечения, окружайте группы соперника и территорию; захваченные группы снимаются с доски. Запрещены самоубийственные ходы и повторение уже встречавшейся позиции. Два паса подряд завершают партию; очки считаются по территории и камням, белым добавляется компенсация 6,5 очка.
- `go-miku.svg` и `go-teto.svg` — отдельные пиксельные спрайты камней для го.

Рекорд merge-игры сохраняется в браузере. Звук можно включать и выключать в игре. Веб-версия рассчитана прежде всего на десктоп и адаптируется к узким экранам. Новые игры добавляются отдельными HTML-страницами и пунктами навигации. Все страницы работают без сборщика и внешних зависимостей; для просмотра откройте `index.html` или запустите локальный HTTP-сервер из папки `web`.
