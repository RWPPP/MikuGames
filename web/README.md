# Игровая комната «Мику и друзья»

Статический сайт без сборщика и внешних зависимостей. Откройте `index.html` или запустите HTTP-сервер из этой папки.

## Игры

- `index.html` — бесконечная игра «Три в ряд».
- `merge.html` — пиксельная merge-игра «Слияние звёзд»: роняйте фишки, соединяйте только одинаковых персонажей и открывайте следующую ступень.

Рекорд merge-игры сохраняется в браузере. Звук можно включать и выключать в игре. Веб-версия рассчитана прежде всего на десктоп и адаптируется к узким экранам. Новые игры добавляются отдельными HTML-страницами и пунктами навигации.
