# Веб-версия «Три в ряд»

Статическая десктоп-ориентированная версия игры без сборщика и внешних зависимостей. Откройте `index.html` в браузере или запустите любой локальный HTTP-сервер из этой папки.

Папка `web/` находится в отдельной ветке `web-games` репозитория `RWPPP/tri_v_ryad`. Android-проект остаётся в основной части репозитория.

В библиотеке пока доступна одна игра. Новые игры можно добавлять отдельными страницами и пунктами игрового меню.
