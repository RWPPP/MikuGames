# MikuGames

Android-приложение включает «Три в ряд», «Слияние звёзд» и го. В «Три в ряд» собирай комбинации из трёх и более фишек; квадрат из четырёх одинаковых запускает отдельный мощный эффект, а если ходов не осталось, поле перемешивается. В merge-игре можно объединять персонажей, а их округлые контуры столкновений позволяют фигуркам катиться.

## Веб-версия

- `web/index.html` — настольная версия игры, рассчитанная в первую очередь на десктоп.
- `web/merge.html` — merge-игра «Слияние звёзд» с цельными PNG-силуэтами и устойчивой физикой Matter.js. Цепочка начинается с Лена и Кайто; пляжный набор открывается после 10 нажатий на Мику. Летняя коллекция доступна сразу. Смена стиля начинает новый забег.
- `web/go.html` — го на стандартной доске 19 × 19: вдвоём или против Тето-компьютера с тремя уровнями сложности. Два паса завершают партию, счёт включает территорию и камни. Компьютер отвечает пасом при отсутствии тактической угрозы и преимуществе по очкам; результат показывается в модальном окне. Есть кнопка «Сдаться».
- `web/go-miku.png` и `web/go-teto.png` — новые пиксельные спрайты для камней в го.
- `web/miku.png` — пиксельная Мику.
- `index.html` — входная страница GitHub Pages, перенаправляет к игре.
- GitHub Pages публикует ветку `web` из корня репозитория. Корневой `index.html` этой ветки перенаправляет в `/web/`.

## Android-проект

`TriVryad-android-project.zip` — проект Android Studio. Внутри находятся исходный код приложения, игровые ресурсы и настройки Gradle.

- `app/src/main/assets/index.html` — игра «Три в ряд» и вход в остальные игры Android-версии.
- `app/src/main/assets/merge.html` и `merge-sprites/` — merge-игра с пиксельными спрайтами и фигурными хитбоксами.
- `app/src/main/assets/go.html`, `go-miku.png`, `go-teto.png` — игра го, доступная из библиотеки игр.
- `app/src/main/java/ru/kotik/trivryad/MainActivity.java` — Android-экран с WebView.
- `app/src/main/AndroidManifest.xml` — настройки запуска приложения.
- `app/build.gradle`, `build.gradle`, `settings.gradle` и `gradle.properties` — конфигурация сборки.

## Сборка APK

GitHub Actions собирает debug APK, когда в `main` меняется архив `TriVryad-android-project.zip` или workflow `.github/workflows/build-apk.yml`. Веб-файлы не запускают пересборку APK. Workflow также можно запустить вручную через **Actions → Build Android APK → Run workflow**. Готовый артефакт `TriVryad-debug-apk` хранится 14 дней; сам APK в Git не добавляется.

## Проверка веб-игр

`node tests/games.cjs` проверяет захваты и запрет самоубийства в го, проигрыш по очкам, окно результата, выбор тактического хода компьютером, слияния, устойчивость стопки, ограничение вращения, проигрыш при переполнении и открытие пасхалки после 10 нажатий.

PNG загружаются без преобразования в WebP. Отрисовщик удаляет маленькие изолированные остатки нарезки и сохраняет исходное разрешение. Контуры столкновений — округлые овалы с пропорциями персонажей; плоские грани нарезки не мешают качению. Трение снижено, поворот не ограничен фиксированным углом.

Значки библиотеки определяются общим `web/navigation.css`. В го есть звуки постановки камней, захвата, недопустимого хода, паса и результата; кнопка динамика сохраняет выбор. `node tests/audio.cjs` проверяет звуки, сохранение настройки, повторное использование аудиоконтекста и немедленное отключение звука.
