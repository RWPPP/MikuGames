# Три в ряд

Бесконечная офлайн-игра «три в ряд» для Android. Поле 8×8, шесть видов фишек, счёт, ходы и локальный рекорд. Каждые 500 очков повышается уровень; если допустимых ходов не осталось, поле перемешивается.

## Скачать APK

GitHub Actions автоматически соберёт APK после добавления workflow. После запуска откройте вкладку Actions, выберите завершённый запуск и скачайте артефакт TriVryad-debug-apk. Внутри архива находится app-debug.apk.

## Сборка в Android Studio

Откройте папку проекта из архива, дождитесь синхронизации Gradle и выберите Build → Build Bundle(s) / APK(s) → Build APK(s).

Приложение работает без интернета и не запрашивает разрешений.
