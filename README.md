# MikuGames — Web

Эта ветка содержит статический сайт с браузерными играми «Мику и друзья». Страницы сайта находятся в папке `web/`; корневой `index.html` перенаправляет на игровую библиотеку.

## Игры

- `web/index.html` — бесконечная игра «Три в ряд».
- `web/merge.html` — пиксельная merge-игра «Слияние звёзд»: одинаковые персонажи сливаются, а фишки отскакивают, вращаются и перекатываются.
- `web/go.html` — го для двух игроков на классической доске 19 × 19. Мику играет чёрными, Тето — белыми. Есть захват групп, правило ко, запрет самоубийственных ходов и подсчёт территории после двух пасов.
- `web/go-miku.svg`, `web/go-teto.svg` — пиксельные камни Мику и Тето для го.
- `web/miku.png` — пиксельная Мику для игры «Три в ряд».

Сайт не требует сборщика или внешних библиотек. Чтобы запустить локально, откройте `web/index.html` или запустите HTTP-сервер из корня репозитория. GitHub Pages публикует сайт из этой ветки.
